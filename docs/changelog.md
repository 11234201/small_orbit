# 版本记录

## 1.0.0-rc.6+8 — 2026-11-10

- Windows 右上角窗口菜单新增“仅显示待办”：隐藏标题、输入和筛选控制，保留当前展示和分组翻页。顶部细条拖动，边缘缩放，右上角小菜单可添加、撤销、恢复完整界面和退出。
- 新增独立“窗口置顶”开关。两个偏好保存于本机，重新打开和从托盘恢复时继续应用；托盘右键菜单也能切换。失败时保留原设置并提示重试。
- 简洁模式支持 Ctrl+N 添加、Ctrl+Z 撤销、Esc 恢复；切换时保留未提交的输入、当前任务视图和撤销记录。
- 简洁窗口允许缩到约260×300；修复该尺寸大字号卡牌溢出。原三种展示与运动节奏、失焦继续播放、隐藏停帧均保留。

新增10项Flutter回归及7项窗口选项、2项尺寸原生检查；数据格式仍为1，Android签名沿用。验证证据见 [验证记录](validation.md)，示例渲染见 `preview/window_modes/`。

## 1.0.0-rc.5+7 — 2026-11-10

根据新的上手反馈重新安排任务，先提交rc.4基线 `dbf6708`，再修复失焦动画与长标题。

- 可见但失去焦点的窗口继续运动；失焦期间取消悬停/键盘焦点的固定，返回窗口后恢复点选保护。最小化、托盘、暂停及减少动态仍会停止动画。
- 长标题最多两行，超出省略，不根据标题长度缩小字号；原文、编辑、搜索和无障碍标题保持完整。悬停显示全文，窗口失焦时收起提示。
- 全文菜单支持滚动，保留可见的编辑/删除按钮；同时修复320宽大字号下展示和运动下拉菜单溢出。
- 沿用数据格式1、Android签名和全部三种运动节奏。持续摆放可选择“一直轻轻漂浮”或“一直活泼弹跳”；开场模式仍按设计停止。

新增10项回归，覆盖失焦、隐藏、焦点恢复、长标题、小屏大字号、全文编辑与悬停。失败复现及最终验证见 [验证记录](validation.md)。

## 1.0.0-rc.4+6 — 2026-11-10

根据上手反馈重新打磨泡泡外观和运动，任务备份格式仍为1。

- 透亮渐变、彩色薄边、柔和高光；减少泡泡内的小字，重要/紧急程度继续通过大小表达，具体档位保留在编辑和概览。
- 连续变化的漂浮方向、不同速度与轻微呼吸；接近时缓冲，碰撞时表面挤压回弹，文字和点按区域保持稳定。
- 完成时短暂散成薄圈与光点；保存立即发起，失败恢复，减少动态时直接完成。
- 三种运动节奏仍可选；暂停、隐藏停帧、按住/悬停/聚焦固定目标均保留。物理细分步长改善不同刷新率下的运动一致性。

新增6项运动回归，完整99项Flutter测试和静态分析通过。实际Flutter界面预览位于 `docs/preview/bubble_refresh/`，不代替目标设备上的帧率/耗电测量。

## 1.0.0-rc.3+5 — 2026-11-10

继续排查异常顺序、跨时区和存储上限的修复版；任务备份格式仍为1，原 Android 签名不变。

- 提醒同步失败后清除“上次成功配置”缓存，撤销变更也会重新同步，避免原生状态停留在失败的中间状态。
- Android 区分已成功保存的配置和待重试协调的旧快照，返回前台或旧广播不再提前使用失败配置；回执达到上限时按日期淘汰，保留当天去重记录。
- Windows 新回执按本地日期/分钟去重，修复时区变化后的重复提示；兼容旧回执的正常升级。
- 跨天补历史保存失败不再把有效数据库锁在恢复页，仍能导出和删除；提醒检查不再依赖历史补全写入成功。
- 恢复期间禁止关闭设置面板操作旧状态；卡牌按任务身份保持当前选择；修复小屏大字号下每周重复选项溢出。

复现证据、回归及兼容边界见 [验证记录](validation.md)。

## 1.0.0-rc.2+4 — 2026-11-10

代码审查修复候选版，数据格式仍为 1，沿用 Android 签名。

- 临时读取失败不再触发旧副本回退；区分损坏版本字段与真正的较新文件格式。
- 多个设置变更在队列中按最新状态执行，快速改动和改回原选项不会互相覆盖。
- 重复任务改回单次不会被旧完成状态隐藏；新增或改期后的漏做历史在同次保存补齐；标题长度与界面的 Emoji 计数一致。
- 编辑保存失败保留草稿；保存中防止重复提交、退栈和重复创建。纸片动画按任务绑定，避免相邻任务继承完成动画。
- Windows 提醒回执写失败会继续尝试持久化；退出失败恢复写入与提醒服务；批量提醒逐项检查跨日时间。
- Android 更新任务时保留无关的已显示通知；先持久化新配置再取消旧闹钟，损坏的提醒缓存可重建。
- Android 回执落盘失败保留待重试状态；配置保存失败后撤销任务变更时，按最终任务状态协调通知，避免误清有效通知。

自动化回归、两端构建和待验证边界见 [验证记录](validation.md)。

## 1.0.0-rc.1+3 — 2026-11-10

个人离线功能收尾候选版，保留数据格式1和原签名。真机/连续使用验收未完成。

- 泡泡按任务身份保留位置，删项不改变其余泡泡大小；触摸、悬停、键盘聚焦时固定目标，完整标题可在概览查看。
- 三种展示都有可搜索概览；完成立即保存，短动效可取消；保存失败恢复显示，减少动态时不等待动画。
- Windows 记住本机窗口位置/尺寸并处理离屏和DPI变化；显式退出等待保存，失败保留窗口；输入框内 Ctrl+Z 撤销文字。
- 原生窗口可见性联动动画，隐藏/最小化时停止绘制动效，提醒服务继续运行。
- 启动文件损坏时可从备份恢复，先原样保全当前/上次/中断文件并校验；较新格式仍禁止降级覆盖。
- 优化多年重复任务的历史补全、最近历史查询和模型解码；有固定样本前后测量及5000步语义对照。
- 提供 ARM64 小包与通用 APK，统一版本代码3并核对签名沿用，方便后续覆盖升级。

使用与升级见 [使用说明](user_guide.md)，测试和未验证边界见 [验证记录](validation.md)，数据与Windows测量见 [性能记录](performance.md)。

## 0.1.1-rc.1+2 — 2026-11-10

候选版，正式发布仍需完成 Android 15、Windows 10/11 的原生验收与连续使用。

- 修复旧编辑窗口可能覆盖最新完成记录的问题；保存失败保留撤销，延迟点击不完成已经改期的任务。
- 导出等待先前保存结束；旧版本应用遇到新版数据时保留文件，不用旧副本自动覆盖。
- 提醒初始化或更新失败后自动重试，设置增加“重试提醒”；编辑任务先保存，权限处理失败不会丢失已保存的小事。
- Android 显示“小事提醒”类别的关闭状态，从系统设置返回自动刷新；关闭的类别不记录为已送达。
- Windows 发送多条提醒时逐项核对当前任务，跳过期间已删除的任务。
- 版本号统一由 pubspec 管理，构建脚本生成独立版本包，校验脚本核对包版本与完整性。
- 29 项 Flutter 测试、5 项 Android 单测通过，两个 release 包构建及完整性检查通过。原生验收范围见 [验证记录](validation.md)。

升级前可导出一份备份。Windows 从托盘退出后解压新包；Android 直接覆盖安装，不卸载。数据格式仍为 1，保留原 Android 签名。
