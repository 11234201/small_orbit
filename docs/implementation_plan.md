# 离线版实施计划

2026-11-10：用户已授权按当前方案开发 Windows 与 Android 离线版。

## 技术与交付

- Flutter 共用界面、任务模型、重复周期、备份格式和泡泡物理行为。
- Flutter、Android SDK、JDK 与 Android 构建/测试放在 mfs-remote；项目路径 /home/wzh/my_code/todo_list。
- Windows 编译使用本机已有 Visual Studio 2022 C++ Build Tools 和 Windows SDK。Linux 不能完成 Windows 桌面集成与原生打包，因此本地 Windows SDK/构建缓存仅用于这一必要能力，并集中在项目的忽略目录内。
- Android 接入原生 AlarmManager、通知权限和重启接收器；重复提醒逐次安排，避免有限未来队列到期。
- Windows 接入托盘与系统通知；关闭窗口后在托盘继续提醒，明确退出应用后停止提醒。首版不安装系统服务，不依赖在线账户。
- 交付 Windows x64 便携 ZIP 与可侧载的 Android APK，保留源码、锁定依赖及构建说明。

## 实施顺序

1. 配置隔离工具链，固定 Flutter 与依赖版本，生成两端工程。
2. 实现严格校验的数据模型、本地耐久保存、重复周期、完成/撤销和带校验的导入导出；导入前自动备份。
3. 实现中文界面、三种展示、重要/紧急大小映射、三种运动节奏、分页与编辑。
4. 接入 Android 后台提醒、Windows 托盘提醒与小窗口行为。
5. 在 Linux 运行模型、存储、物理与界面测试，构建 APK；在 Windows 编译并做实际桌面烟雾检查。
6. 输出安装包、校验值、使用说明与已验证/未验证边界。

## 当前采用的产品默认值

- 工作名：小事星球。首次默认泡泡，开场弹跳后逐渐停止；记住展示和运动选择。
- 重要度和紧急度手动各三档、等权映射面积；首版不自动修改紧急度。
- 每天/每周重复按本地日历推进；未完成旧期保留可计算历史，不堆积在当前待办。
- 首版兼容 Android 8.0+、Windows 10/11 x64；用户已确认实际使用 Android 15 和 Windows 10/11，作为重点验证目标。

## 当前实现记录

Flutter 共用界面、校验备份、保存恢复和重复周期已实现；Windows 原生托盘与小窗口已编译打包，Android 已生成签名 Release APK。14 项核心测试、2 项交互测试、1 项多尺寸布局测试和 5 项 Android 原生日历调度测试已通过；静态分析无问题。预览位于 `docs/preview/`，包含实际 Flutter 渲染的中文字体和图标。产物与验证边界见 `validation.md`。
