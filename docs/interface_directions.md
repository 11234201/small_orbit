# 展示模式与泡泡动效

日期：2026-11-10。状态：三种展示全部保留、默认泡泡；大小分级与运动选项已纳入需求。

## 用户反馈

用户认为第一轮条列式草图“太严肃太无趣”，希望更灵动的展示与消除 todo 形式。继续保留此前已确认的离线、日期提醒、重复任务、导入恢复和小窗口要求。

之后用户明确选择：三种展示都保留、可自选、默认泡泡；泡泡大小代表重要和紧急程度；打开界面可以乱飘乱弹，三种运动节奏也都可选。

## 三种展示模式

### 泡泡消消乐

任务是一颗带文字、时间和重复标记的柔和气泡。重要或紧急的任务更大，泡泡会互相碰撞、碰边界反弹。点一下完成，气泡弹缩并散成小点。鼠标靠近、键盘聚焦或按下时固定对应泡泡；长文字、任务很多时的呈现需要继续设计。

已确认作为首次打开的默认模式。

### 纸片收纳

任务像轻微倾斜、贴有胶带的小纸片。点一下，纸片卷起缩小，落入完成口袋。文字有更充足的展示空间，手感更接近日常便签。后续需验证触屏下是否需要滑动收纳，以及如何区分编辑和完成入口。

### 抽卡清空

当前任务位于牌堆最上方，右划完成，下一张出现；也有“完成，划走”按钮。“换一件”只切换当前任务，不表示完成或跳过日期。适合聚焦眼前一件事，但需要补充快速概览其他任务的入口。

## 共同行为与约束

- 提供展示选择器，泡泡、纸片、卡牌共用一份任务；切换不复制或重建任务，不改变提醒与重复规则。
- 建议记住每台设备上次选择的展示模式和运动节奏。首次没有偏好时默认泡泡。
- 消除代表完成，数据进入完成记录；重复任务只完成当期，下一期按原计划出现。
- 支持跨模式撤销。用户无需为消除操作额外付出多步成本。
- 任务文字、提醒时间和重复标记清楚可见。
- 运动节奏可选，提供暂停/继续，尊重减少动态效果设置；界面不可见时暂停计算。
- 三个方向的名称都是临时概念名，未确定正式产品名。
- 草图使用示例任务，不运行真实提醒、备份或重复周期调度；最多同时展示 6 个任务是预览边界，不是正式产品限制。
- 视图范围、历史记录、导入恢复等已确认能力会整合进三种模式，不因为当前草图省略入口而取消需求。

## 泡泡大小

用户确定大小同时表达重要与紧急。草图先采用：重要度、紧急度各三档，等权组合，再映射到面积；提升任一维度都使泡泡变大。文字标签仍分别显示两个维度，同样大小不代表重要度与紧急度完全相同。

重要度与紧急度的档位、权重和时间自动变化规则尚未最终确定。当前新增任务可手动设定；没有实现按截止时间自动放大的行为。适配窗口时整体尺寸范围会变化，但同一窗口内的大小排序保持一致。

## 泡泡运动

- 开场弹一阵：初始有活力地运动，随后减速，草图约 6.5 秒后停止。
- 持续缓漂：持续低速移动，与其他泡泡和边界碰撞弹开。
- 持续活泼：持续较高速度移动与碰撞。

用户要求三种都可选，没有明确指定运动的默认值。草图先默认开场档，并保留选择。选择持续运动代表允许相应的循环动画，替代前一轮的“闲置不动”假设。
