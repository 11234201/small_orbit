## 3. 首次工程验证的重点

1. 一条任务从创建、编辑、完成、撤销到重启恢复的完整路径。
2. Android 与 Windows 互相导出、导入中文任务、重复规则及历史记录；替换前备份并可回退；无效文件与备份失败不破坏已有数据。
3. Windows 小窗口及 Android / Windows 系统提醒：优先验证改期、完成后取消、窗口关闭、设备重启和重复提醒的后续调度。Flutter 通知插件的 Windows 周期接口有限制，不能直接复用 Android 调用便宣布完成。
4. 使用发布构建测量启动、空闲资源和分发包，记录参考设备；数值门槛等优先级明确后确定。
