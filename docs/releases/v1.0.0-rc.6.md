# 小事星球 v1.0.0-rc.6 · Windows / Android 离线候选版

这是小事星球的首个 GitHub 公开预发布版本。源码采用 MIT 许可证；版本为 `1.0.0-rc.6+8`，备份格式仍为 1。

## 本版功能

- 泡泡、纸片、卡牌三种待办展示；默认泡泡，大小表达重要和紧急程度。
- 轻巧的完成反馈、三种运动节奏、暂停及减少动态选项。可见但失焦的 Windows 窗口继续运动。
- 快速添加、日期与提醒、每日/每周重复、搜索概览、历史和撤销。漏做的旧周期记入历史，不堆积重复待办。
- Windows 可选“仅显示待办”和“窗口置顶”，两项独立记忆；支持拖动、缩放、托盘和快捷键。
- 两端独立离线，手动导出/整份恢复 `.orbit` 备份，替换前自动备份。无需账户，不自动同步。

## 安装与升级

Windows 更新前，从旧版托盘菜单选择“退出”，再启动新版；仅点关闭会收进托盘。任务仍从本机应用数据目录读取。

Android 通用与 ARM64 包使用同一发布签名，可覆盖此前同签名的小事星球版本。先导出备份，不要先卸载；首次提醒需要系统通知权限，准时提醒权限在设置中检查。

桌面一角使用：先选择持续漂浮或持续活泼，再在右上角窗口菜单勾选“仅显示待办”和“窗口置顶”。简洁模式顶部可以拖动，右上角 `⋯` 可添加、撤销及恢复完整界面，待办界面按 `Esc` 也能恢复。
