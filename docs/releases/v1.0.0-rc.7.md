# 小事星球 v1.0.0-rc.7 · 窗口透明度

Windows新增整个窗口的透明度调节，版本为 `1.0.0-rc.7+9`。本版继续标记为预发布，采用MIT许可证。

## 使用方法

右上角 **窗口选项 → 窗口透明度**，调节不透明度30%～100%（每档5%）。松开滑块后整个窗口生效并保存，100%完全不透明。完整界面和简洁模式均可使用，与置顶独立。

重新打开和从托盘恢复后继续应用；面板的“恢复不透明”或托盘右键的“恢复完全不透明”可一键复原。旧版窗口设置自动兼容，保存失败保留原设置。另修复初次置顶请求返回成功但实际未生效的边界。

## 安装包

- `small_orbit-1.0.0-rc.7-windows-x64.zip`：Windows 10/11 x64，解压完整目录后运行。
- `small_orbit-1.0.0-rc.7-android-arm64.apk`：Android 8.0+ ARM64小包。
- `small_orbit-1.0.0-rc.7-android.apk`：Android 8.0+通用包。Android本版无桌面透明度功能，沿用相同应用数据和发布签名，版本码9。
- 同附 `SHA256SUMS-1.0.0-rc.7.txt`、`SOURCE_SHA256-1.0.0-rc.7.txt` 和 `LICENSE.txt`。

Windows更新前请从托盘退出旧版再开新版。Android覆盖安装前建议导出备份，不要先卸载。任务备份格式仍为1。
