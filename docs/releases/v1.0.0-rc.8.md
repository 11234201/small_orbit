# 小事星球 1.0.0-rc.8

2026-11-14，本地候选版，构建号 10。六种趣味玩法已接入，未公开发布；此前 rc.7 下载附件保持不变。

## 开始体验

打开右上角“玩法与小世界”；简洁窗口通过 `⋯` 菜单进入。

- **引力小星系**：开启空白处引力，体验失重、月球、果冻三种手感。
- **材质实验室**：经典、布丁、水滴、肥皂泡；完成轻音效和 Android 触觉默认关闭。
- **今日星座**：完成的小事化为星星，按日期浏览、分页和查看来源；撤销会撤回纪念。
- **专注卫星**：点选或拖入任务，设置时长，暂停、继续或提前结束；到点由你决定是否完成。
- **条件扭蛋**：随机、5 分钟、轻松、今天最重要四种条件，抽中后可进入专注。
- **我的小岛**：完成纪念解锁 12 种装饰，支持拖动、方向微调和一键整理。

同时包含此前未公开的背景透明、全局慢漂、拖拽及 Android 提醒容量改进。操作与数据规则见[使用说明](../user_guide.md)，五页预览在 `docs/preview/fun_features/`。

## 升级与备份

先在旧版导出备份，再打开新版。格式 2 可读取旧格式 1；首次保存新版数据前，会将旧文件原始字节保留在备份目录。收藏、玩法偏好和小岛布局进入任务备份，活动专注与设备音效偏好仅保存在本机。旧版不能直接读取格式 2，回退时使用升级前备份。

星座与小岛共用完成纪念。删除任务保留匿名纪念；清除匿名纪念会减少成长。恢复备份为整份替换，且会结束当前专注，不叠加奖励。

## 验证与边界

- 静态分析通过，最终全量 150 项 Flutter 测试通过，27 项 Android JVM 测试通过。
- 五页在 260×300、390×720、900×760 和 1.8 倍字号下无布局溢出；实际 Flutter 渲染图已检查。容量样本覆盖 10,000 任务、250,000 条完成历史。
- Windows Release 构建和 0/100/1000 任务的隔离隐藏启动、正常退出检查通过。该启动检查在最后的星图绘制调整前执行，最终包已重新构建并校验。
- **Windows 原生位置/尺寸检查 6 项通过，但窗口选项的首项置顶检查失败，后续项未执行。** 诊断为调用成功却未观察到置顶标志，相关实现与本轮开始一致，原因待真实桌面确认。
- Android 锁屏、厂商后台、重启后提醒、声音和触觉仍待真机；Windows 桌面透明合成、多屏、置顶与连续一周使用仍待设备验收。未宣称真机升级、耗电或可见交互性能已验证。
