# 小事星球 1.0.0-rc.9

2026-11-14，本地候选版，构建号 11。修复 Windows 置顶并完成一轮代码检视；未公开发布，原 rc.8 文件保留。

## 本次修复

- Windows 首次置顶、隐藏恢复和取消置顶正确生效，同时保持其他窗口层级和焦点。实际样式不匹配时回滚并拒绝保存。
- 从旧格式恢复副本启动，先永久归档原始数据再升级，归档失败保持源文件不变。
- 已排队的旧专注计时事件不会干扰新会话；退出等待保存失败时保留窗口，允许重试。
- 小岛拖动复用收藏统计，避免逐帧重复扫描。六种玩法入口和使用方式不变。
