# 小事星球离线版

当前公开候选版：1.0.0-rc.7。本地候选版为 1.0.0-rc.10+12，包含六种玩法、背景透明、全局慢漂和拖拽改进，并修复 Windows 首次置顶、升级备份、专注并发与通知重试；公开 rc.7 下载包尚不包含这些内容。以下按 rc.10 说明；原生提醒送达和连续使用仍按设备验收清单验证。

## 玩法与小世界

完整界面右上角星光按钮打开“玩法与小世界”，Windows 简洁模式通过 `⋯ → 玩法与小世界` 进入。顶部标签可横向滚动；左上角返回待办。五个页面容纳六种玩法，泡泡、纸片和卡牌共用完成纪念。

- **引力小星系**：在“手感与材质”开启空白处引力，选择失重、月球或果冻手感。返回泡泡界面，按住空白处并移动，泡泡会围绕触点运动，松开逐渐散开。按住任务仍按原来的点击、编辑和拖动规则操作；暂停或减少动态时引力停用。
- **材质实验室**：选择经典、布丁、水滴或肥皂泡，任务文字和重要/紧急大小含义不变。可单独开启完成轻音效，Android 还可开启轻触觉反馈；默认关闭。声音受系统音量设置影响。
- **今日星座**：完成一件小事点亮一颗星；左右切换有纪念的日期，较多星星分页展示，点星星查看详情。按实际完成日归档；旧记录缺少原时区，按升级时设备时区推算并明确标注。撤销和历史重开会撤回星星，重复完成同一期不会叠加。
- **专注卫星**：选择任务，或长按下方任务拖入轨道，再点开始。支持 5/15/25/45 分钟及 1～180 分钟自定义、暂停、继续和提前结束；到点仅提示，由你决定是否完成任务。可以从任务的编辑菜单选择“专注这件事”。切换任务会先询问是否结束当前一段。Windows 托盘运行时计时继续，明确退出后不实时提醒；Android 后台提示受系统通知、准时提醒权限和省电设置影响。重开恢复本机专注状态，异常系统时间会提示确认；活动专注不随备份在另一设备启动，恢复备份会结束当前专注。
- **条件扭蛋**：从随机、5 分钟、轻松、今天最重要中选择条件，再点“抽一件”。同一轮尽量不重复，耗尽后开始下一轮。“换一件”不完成或改期任务，抽中后可进入专注轨道。5 分钟和轻松条件只使用已填写的信息；详细编辑的“耗时与精力（可选）”可填写 1～480 分钟及轻松/普通/费力，快速新增仍只需标题。
- **我的小岛**：每份有效完成纪念贡献一次成长，依次遇见 12 种花草、树和建筑装饰。拖动摆放，或选中后使用方向按钮微调；“一键整理”恢复默认布局。撤销/历史重开会重算成长，暂时未解锁的装饰保留摆放位置，重新满足条件后恢复。漏做或离开几天不扣成长。

删除任务后，已经获得的星星和装饰作为匿名纪念保留，不显示原任务文字；撤销删除可重新关联。在小岛页面可明确清除匿名纪念，清除会减少星星和成长，建议先导出备份。星座与小岛共用同一份纪念，恢复备份是整份替换，不会叠加奖励。

减少动态时可继续使用静态星图、小岛、专注数字和抽取结果。玩法页面内容可纵向滚动，小窗口下仍可使用全部入口。

专注保存期间若目标被删除、完成或被备份替换，会结束这段专注；结束保存失败时保留原页面并允许重试。通知暂时未能显示时，回到应用会再尝试；Windows 已显示的提示会记录在本机，避免重开后重复弹出。任务已完成或会话已结束后，不补发旧提示。Android 是否实际送达仍取决于系统权限与后台限制。

## 安装和打开

Windows 10/11 x64：解压整个 ZIP，打开 `small_orbit.exe`。保留旁边的 DLL 和 data 文件夹。便携包包含 Visual C++ 运行库，不需要安装 Flutter。

Android 8.0+（重点使用环境为 Android 15）：将 APK 复制到手机，使用系统安装器安装；安装器要求时允许当前文件来源安装。首次设置提醒时请求系统通知权限。应用无需网络和账户。

普通 ARM64 手机可选文件名含 `android-arm64` 的小包；不确定设备架构时用 `android.apk` 通用包。两者使用同一签名。升级直接覆盖安装，先导出备份，不要先卸载旧版。

## 添加和完成

顶部输入标题，回车或点加号即可添加。输入框里的调整图标打开详细编辑，可设置日期、提醒时间、每日/每周重复，以及三档重要程度和紧急程度。

标题最多 240 个可见字符，包含 Emoji。详细编辑保存成功后才关闭；保存失败会保留草稿，可直接重试。保存过程中暂时不能返回或重复提交。

默认泡泡展示，泡泡面积随重要与紧急程度一起增加。轻点泡泡完成，长按或点铅笔编辑；纸片点勾收进口袋；牌堆一次展示一件小事，可向右划走或点“完成，划走”。“换一件”只换当前卡牌，不完成任务；“看看其他小事”提供概览。底部“撤销”恢复刚完成或删除的任务，切换展示仍可撤销。

“今天”显示今天、未完成的过去任务和未设日期的任务；“全部”还显示未来安排。较多任务分组展示，可翻页，没有六条任务的录入限制。

三种展示都提供概览，可按标题搜索当前视图中的任务、查看完整长标题及重要/紧急档位，再跳到所在组。新增或完成任务时，剩余泡泡尽量保持原位和大小；按住、鼠标悬停或键盘聚焦会固定目标。保存失败时任务会恢复显示并提示重试。

运动可选开场弹跳后安静、一直缓漂或一直活泼，也可暂停或在设置中减少动态效果。鼠标停在泡泡上时暂时固定，方便点击。

轻漂会缓慢前往待办区域内的不同位置，逐渐走遍窗口，而不是只绕着起点转。这里的“全局”是当前窗口的待办区域，泡泡不会跑出窗口或越过工具栏。

按住泡泡主体拖动，超过拖动阈值后会跟随指针，松开时按方向与速度滑行，随后减速回到原来的运动节奏；碰到边缘会反弹。拖动只影响位置和运动，不完成、删除或编辑任务，也不增加撤销记录。轻点仍完成，长按仍编辑，铅笔按钮仍可直接编辑；从铅笔上开始拖动会取消这次点击，不会甩动泡泡。开场已经安静时，只让拖动的泡泡短暂滑行，之后停下。手动暂停或减少动态时可以挪位置，松手后不滑行。切换应用或隐藏窗口会取消未结束的拖动。

想把窗口放在旁边持续运动，选“一直轻轻漂浮”或“一直活泼弹跳”。切换到其他应用时，只要小事星球窗口仍可见，就会继续运动；失焦期间悬停和键盘焦点不会固定泡泡。最小化、收进托盘、手动暂停或开启减少动态时仍暂停。“开场弹跳 → 慢慢安静”会按设计在开场后停止。

长标题在泡泡内最多显示两行，超出以省略号收尾，不为塞下更多文字而缩小字号。完整内容没有删减：Windows悬停可看全文，长按或点铅笔可打开全文菜单；长内容可以滚动，“编辑”和“删除”按钮仍可见。概览也保留完整标题和搜索。

泡泡使用实色渐变、彩色薄边和柔和高光；主体保持不透明，漂浮轨迹会轻轻转弯，碰撞时略微挤压再回弹，文字保持端正。大小仍表示重要与紧急程度，具体档位可在编辑或概览查看。完成时有短暂的散开反馈，开启“减少动态效果”后直接完成。

Windows 更新时，请先从旧版托盘菜单选择“退出”，再打开新目录的程序；直接点窗口关闭会收进托盘。新程序会读取原有任务，不用重新录入。

## Windows 简洁窗口与置顶

点右上角“窗口选项”，可以独立勾选“仅显示待办”和“窗口置顶”。两项设置都会在本机记住，下次打开继续使用；它们不随任务备份跨设备复制。

“仅显示待办”隐藏系统标题栏、应用标题、输入框、筛选和运动控制，只显示当前的泡泡、纸片或卡牌。当前展示、今天/全部筛选和运动选择保持不变，完整界面未提交的输入也会保留。任务分组较多时保留翻页入口。

拖动顶部细条可以移动窗口，拖动边缘可以调整大小；简洁窗口最小约260×300，恢复完整界面时会扩展到可用的最小尺寸。右上角“⋯”仍可添加、撤销、收进托盘、最小化或退出。选择“恢复完整界面”，或在待办界面按 Esc，可重新显示所有控件；托盘右键菜单也能切换这两项设置。

“窗口置顶”让窗口在切换到其他普通应用时仍留在上层；取消勾选即可恢复普通窗口顺序。想放在旁边持续漂浮，请先在完整界面选择“一直轻轻漂浮”或“一直活泼弹跳”，再进入简洁模式。最小化、托盘、手动暂停和减少动态仍会停止运动。

在右上角“窗口选项 → 窗口透明度”调节背景不透明度，范围30%～100%、每档5%。松开滑块后只改变窗口背景，泡泡、纸片、卡牌、文字和操作控件保持自身不透明度；100%时背景完全不透明。面板里的“恢复不透明”或托盘右键“恢复完全不透明”可以一键复原。透明度与简洁/置顶独立，重启及托盘恢复后保留，不随任务备份跨设备复制。旧版保存的百分比会沿用为背景不透明度。

## 重复与历史

每天任务按本地日历更新；每周任务沿用起始日期的星期，本周任务保留到下一个周周期。漏做旧期留在历史里，当前待办不堆积。

完成当前周期后，“今天”暂时隐藏它，“全部”可看到下一期。历史显示最近 30 天，可撤销完成；更早记录仍保存在备份中。删除重复任务会删除整套规则及其历史，可立即撤销。

将重复任务改回单次后，会作为待办重新出现；以前的单次完成记录归入对应日期的历史。同日已有完成记录时保留该条，按天合并显示。

如果跨天历史暂时无法保存，应用仍打开原来的完整数据，也会尝试现有任务的提醒。可先导出备份，再检查存储空间或删除不再需要的任务；之后会自动重试补全历史。

## 提醒与收起

Windows：关闭窗口或“收进托盘”后继续运行。双击托盘图标重新打开；右键可退出。明确退出、关机或休眠时不会实时提醒；重新打开后只补发当天尚未提醒的事项。Windows 勿扰模式可能隐藏通知。

Windows 记住本机窗口位置和尺寸，屏幕变化后尽量回到可见范围；这个偏好不随任务备份跨设备复制。选择退出时先完成已发起的保存，保存失败会保留窗口。

Windows 新提醒回执按本地日期和提醒时间去重，更换时区后同一期不会再次提示。旧版回执在能够匹配时自动升级；若在首次升级前已经换过时区，旧回执缺少原时区信息，可能补发一次。

Android：通知和准时提醒是两项系统权限，可在设置页检查并进入授权。未允许准时提醒时仍安排系统提醒，但可能延后。重启或改变时区后重新安排；系统“强制停止”后需再次打开应用。不同厂商后台限制仍需在你的 Android 15 手机上实测。

系统应用通知已允许时，还需确认“小事提醒”类别没有关闭。从系统设置回来会刷新状态。提醒更新失败不会撤回已保存的任务，应用会自动重试，也可在设置点“重试提醒”。系统接受通知不等于用户已看到通知。

## 备份与恢复

设置 → 导出备份，得到 `.orbit` 文件。复制到另一台设备，在“从文件恢复”中选择它。恢复替换全部任务和设置；确认前显示任务数，替换前自动备份。备份失败或文件校验失败不会替换数据。

导入、恢复或保存设置期间，面板会暂时禁止关闭，完成后再继续操作任务。

“自动备份”可恢复或导出最近的恢复前备份。两端不自动合并或同步。卸载 Android 应用或删除本地数据前，请先导出。

导出会等待已发起的保存完成。遇到较新版本的数据，旧版本应用会拒绝打开并保留原文件，请更新应用；不要删除原文件来绕过此提示。

如果本地文件及恢复副本均无法读取，启动页提供“重试打开”和“从备份恢复”。恢复前把当前、上次保存和中断文件原样复制到本地 `backups/recovery-*` 子目录并校验；保全失败则不替换。较新版本的数据只允许更新应用后读取。

## 快捷键和边界

Windows：Ctrl+N 在完整界面聚焦快速输入，在简洁界面打开添加面板；输入框内 Ctrl+Z 撤销文本编辑，其他位置 Ctrl+Z 撤销最近任务操作。简洁待办界面的 Esc 恢复完整界面；弹窗中的 Esc 先按弹窗本身的关闭规则处理。更新程序目录前先从托盘退出；数据保存在系统应用数据目录，与 ZIP 解压位置无关。

使用明文本地 JSON 和 SHA-256 备份完整性校验，没有文件加密。rc.8 读取格式 1/2，写入和导出格式 2；首次升级写入前，在本机 `backups/before-format-2-*.orbit` 保全格式 1 原始文件。旧版不能打开格式 2，回到旧版需使用升级前备份。恢复前自动备份流程继续有效。

新格式限 128 MiB、10,000 个任务、250,000 条任务历史和 500,000 条纪念记录；超限会拒绝保存或导入并保留原数据，不静默截断。接近容量时可先导出，再整理不需要的任务和匿名纪念。暂不支持“稍后提醒”或在系统通知内直接完成。
